# DocuMind AI

DocuMind AI is an intelligent document-based chatbot that allows users to upload files (like PDFs) and ask questions in natural language. Using advanced AI (RAG + LLM), it retrieves relevant information from documents and provides accurate, context-aware answers instantly.

---

## Why is it Useful?

* Eliminates the need to manually read long documents
* Provides instant answers from your own data
* Improves productivity for students, developers, and professionals
* Helps in quick research and knowledge extraction
* Keeps your data secure and private

---

## How to Use (Step-by-Step)

1. **Sign Up / Login**
   Create an account or log in using email, Google, or GitHub

2. **Upload Document**
   Upload your PDF or file

3. **Ask Questions**
   Type your query related to the document

4. **Get Answers**
   AI processes your query and gives accurate responses

5. **Manage Profile**
   Update username, password, or settings anytime

---

## What Makes It Different?

* Uses **RAG (Retrieval-Augmented Generation)** for accurate answers
* Powered by **Groq LLaMA 3.1 (fast inference)**
* Works on **your own documents**, not generic data
* Secure authentication (Email + OAuth)
* Clean and intuitive UI for better user experience
* Real-time interaction like ChatGPT
